# Sistema de Cálculo de Equação do 2º Grau (Delta)

Este projeto consiste em um sistema desenvolvido em Java com o objetivo de calcular e resolver equações do 2º grau, utilizando o método de Bhaskara.  
O programa foi criado com elementos da prática de lógica de programação, estruturas condicionais, laços de repetição e organização de código com conceitos básicos de Programação Orientada a Objetos (POO).

## Tecnologias Utilizadas

- javax.swing.JOptionPane para entrada de dados com interface gráfica
- java.lang.Math para cálculo de raiz quadrada


## Conceitos Aplicados

- Estruturas condicionais: if/else if/else
- Laços de repetição: do while
- Aplicação de interface gráfica: JOptionPane
- Métodos e separação de responsabilidades
- Programação Orientada a Objetos (classes e métodos)
- Boas práticas de organização
